# AI чи реальне? — інтерактивний тест для лекції

Невеликий статичний веб-додаток для лекції про штучний інтелект.
Учень бачить дві картинки — одна справжня, одна згенерована AI — і має вгадати, яка саме.

## Що всередині

- `index.html` — сам тест (10 пар зображень, складність зростає від 1 до 5).
- `analitics/index.html` — **прихована** панель організатора зі статистикою.
  Доступна за URL `.../analitics/` — посилання на неї навмисно немає в UI тесту.
- `data/questions.js` — дані питань: шляхи до фото + підказка після відповіді.
- `images/` — папка для локальних зображень (опційно).
- `quiz.js`, `admin.js`, `styles.css` — логіка й стилі.

## Як запустити

Тут немає бекенду — достатньо відкрити `index.html` у браузері.
Для коректного завантаження локальних зображень рекомендую підняти будь-який
статичний сервер у папці `ai-photo-quiz/`:

```bash
# Python
python3 -m http.server 8080

# або Node
npx serve .
```

Далі — http://localhost:8080/

## Як підставити свої фото

1. Поклади пари зображень у папку `images/`, наприклад:
   `images/q1-real.jpg`, `images/q1-ai.jpg`, `images/q2-real.jpg`, …
2. У `data/questions.js` заміни URL-и на шляхи до своїх файлів:

```js
{
  id: 1,
  level: 1,
  real: "images/q1-real.jpg",
  ai:   "images/q1-ai.jpg",
  hint: "На простих AI-зображеннях часто пластикова шкіра і неприродне світло.",
},
```

3. Підтримуються і локальні шляхи, і будь-які зовнішні URL.
4. Рівень (`level`) — від 1 до 5. Питання автоматично відсортуються від
   найпростіших до найскладніших. Можна додавати скільки завгодно питань.

За замовчуванням у `questions.js` стоять placeholder-и з `picsum.photos` —
вони завантажуються по інтернету і потрібні лише щоб додаток «ожив» без
додаткового налаштування. Для лекції їх треба замінити на реальні пари
фото (AI vs справжнє).

## Статистика

Панель статистики — прихована: посилання на неї **немає** в UI тесту.
Щоб її відкрити, зайди на `<адреса-сайту>/analitics/` (наприклад,
`https://finintra.github.io/danyaapp/analitics/`).

Вона показує:
- кількість проходжень, середній і найкращий %;
- % правильних відповідей по кожному питанню (видно, які найскладніші);
- повну історію сесій з датою і балом;
- кнопки «Експорт JSON» і «Скинути статистику».

### Два режими зберігання

1. **Локальний (за замовчанням, без налаштувань).** Результати зберігаються
   у `localStorage` **того браузера, де проходять тест**. Підходить лише
   якщо всі учні проходять тест по черзі з одного ноутбука/вкладки.
2. **Спільний — через Firebase Firestore.** Кожне проходження пише одну
   сесію у хмарну базу, і ти бачиш результати всього класу зі свого компа.
   Нижче — як це увімкнути.

### Як увімкнути спільну статистику (Firebase) — ~10 хвилин

1. Зайди на https://console.firebase.google.com і створи новий проект
   (наприклад, `ai-photo-quiz`). Google Analytics можна не вмикати.
2. В меню проекту: **Build → Firestore Database → Create database**.
   Обери будь-який регіон (наприклад, `europe-west`), режим — **Start in
   test mode** (це дасть 30 днів відкритих правил; нижче скажу як продовжити).
3. Встанови правила (Rules):
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /quiz_sessions/{sessionId} {
         allow read, write: if true;
       }
     }
   }
   ```
   Це дозволить анонімним учням писати свої результати, а тобі — читати їх
   з `/analitics/`. Дані анонімні (без імен), тож проблем з приватністю немає.
4. В меню проекту: **Project settings** (шестерня) → вкладка **General** →
   прокрути до **Your apps** → натисни **Web** (`</>`) → вкажи назву →
   **Register app**. Скопіюй з вигляду:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "...",
   };
   ```
5. Відкрий `ai-photo-quiz/firebase-config.js` і підстав значення у
   `window.FIREBASE_CONFIG` замість `REPLACE_ME`.
6. Закомміть і запушиш — GitHub Pages автоматично переcobере сайт.

Перевірка: відкрий `/analitics/` — угорі має бути зелений значок
«Спільна статистика (Firebase)». Якщо бачиш «Локальна статистика
(Firebase не налаштовано)» — значення у `firebase-config.js` не
застосувались (перевір синтаксис і пуш).

Кнопка «Скинути статистику» чистить і Firestore, і localStorage.

## Клавіатурні скорочення

- `1` — обрати ліве зображення
- `2` — обрати праве зображення
- `Enter` — перейти до наступного питання

## Поради для показу в класі

- Підніми сервер на ноутбуку і передавай його між учнями — або виводь на
  екран і нехай кожен учень називає відповідь вголос.
- Після кожного питання відкривається підказка (`hint`) — це гарний привід
  зупинитись і обговорити, на що саме треба дивитись (руки, тіні, текст тощо).
- Після лекції відкрий `/analitics/` — можна разом розібрати, які питання
  виявились найпідступнішими.
